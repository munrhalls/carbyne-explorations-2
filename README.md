# Carbyne Explorations 2.0

A hand-drawn SVG scene with a river menu. Each river item opens one page.

- Rules and the definition of done: `AGENTS.md`.
## Editing and publishing

- Edit: run `node src/admin/server.mjs`, open http://127.0.0.1:4321/, edit pages, upload images.
- Publish: `git add -A`, `git commit -m "..."`, `git push` — GitHub Pages deploys from `main` within a minute. Cost: zero.
- The admin only listens on your own computer and has no login.
- Old site: github.com/munrhalls/Carbyne-explorations.
